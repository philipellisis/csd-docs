# Reset Config

### Reset to factory defaults

1. Connect to the PinOne Ultra in the config tool.
2. On the home page, click the `Restore Configuration to Defaults` card.
3. Click `Save Config` in the header to send the default settings to the board. The tool will not change the board until you do this.
4. Unplug the USB cable and plug it back in so that all settings are re-read.

### Restore a previous configuration

If you have saved a backup using `Backup Configuration to PC`, you can put it back with `Restore Configuration from PC` and then `Save Config`. It is a good idea to take a backup once you are happy with your setup.
