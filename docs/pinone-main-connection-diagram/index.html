Which wires do I need?

Almost every part comes with the wires it needs. The exception is the wire from the main board to the life extenders, which is sold separately as the Terminal Connector Wire:

  • 3 terminal wire for each 2 position life extender (outputs 1–2 and 6–7)
  • 4 terminal wire for each 3 position life extender (outputs 3–5 and 8–10)
Check polarity

The expansion board cable, the ribbon cables and the strobes can all be plugged in backwards. A reversed ribbon cable won't damage anything, but the buttons or lights won't work. Reversed strobes can damage the strobes or the expansion board. Hover over each wire in the diagram for details.

You don't need every part shown. Start with the main board and power supply, then add the parts you want. See DIY Cabinet Options for help choosing parts, and the Builders Kit guides for close-up photos of each connection. Using the smaller board? See the PinOne Mini visual connection diagram.
